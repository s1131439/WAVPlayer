# WAV Player

## 程式簡介
WAV 音效播放器，可以播放 `.wav` 音效檔案，並提供基本的播放控制功能。

---

# 用途
- 播放 WAV 音效檔

---

# 功能介紹
- 瀏覽並選擇 WAV 檔案
- 播放音效
- 循環播放音效
- 停止播放
- 關閉程式確認視窗
- 顯示播放狀態
- 顯示檔案資訊
- 支援拖曳 WAV 檔案
- 錯誤處理與防呆功能

---

# 使用說明

## 1. 選擇 WAV 檔案
- 點擊「瀏覽」按鈕
- 選擇電腦中的 `.wav` 檔案

## 2. 播放音效
- 點擊「播放」按鈕即可播放音效

## 3. 循環播放
- 點擊「循環播放」按鈕可重複播放音效

## 4. 停止播放
- 點擊「停止」按鈕可停止音效播放

## 5. 拖曳播放
- 可直接將 WAV 檔案拖曳到程式視窗中

---

# 新增功能

- 播放狀態顯示
  - 播放中
  - 循環播放
  - 已停止

- 防呆檢查
  - 檢查是否選擇檔案
  - 檢查檔案是否存在

- 檔案資訊顯示
  - 檔名
  - 檔案大小

- 拖曳檔案功能

- 安全停止功能
